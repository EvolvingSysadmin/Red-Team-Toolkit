# Bookmarks

A curated set of reference sites I return to across engagements.

## Why It Matters

A short, trusted set of references beats searching mid-engagement. These are the sites that reliably have the command, technique, or payload I need.

## Reference

### Technique References

| Resource | Use |
| :--- | :--- |
| [HackTricks](https://book.hacktricks.xyz/) | Broad methodology and per-service enumeration |

| [GTFOBins](https://gtfobins.github.io/) | Unix binaries for privilege escalation and bypasses |
